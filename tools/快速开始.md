# 怎么更快更新站点

无服务器：本地改文件 → 预览 → git push（GitHub Pages）。

## 闪念
```powershell
python tools/new_memo.py "内容"
```

## 文章
中文标题必须带英文 slug：
```powershell
python tools/new_post.py --title "标题" --slug english-slug --tags AI,Agent --excerpt "摘要" -f body.md
```

## 预览
```powershell
python serve.py 5500
```
打开 http://127.0.0.1:5500/

## 上线
```powershell
python tools/publish.py "说明" --push
```

## 自检
```powershell
python tools/selftest.py
```

## UI
全站视觉在 `styles/custom.css`（蒙德里安：红/蓝/黄色块 + 粗黑线）。改完后 bump HTML 里 `custom.css?v=`。
