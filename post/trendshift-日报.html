Trendshift每日热榜精选。今天挑了5个有意思的项目：能自己做交易决策的AI Agent、不怕反爬的自适应框架、给Claude Code加速的知识图谱、开源视频编辑器，以及让AI真正"记住东西"的记忆引擎。

1. Vibe-Trading — AI交易Agent

GitHub：HKUDS/Vibe-Trading

香港大学数据科学实验室出的项目。简单说，这是一个用自然语言驱动的交易Agent。你告诉它你的交易策略（比如"BTC跌破MA30就做空"），它会自动获取市场数据、分析信号、执行交易。

和市面上那些量化框架不同，Vibe-Trading的核心卖点是"Vibe"——你不需要写Python代码定义策略，直接用中文或英文描述你的想法，Agent自己去理解和执行。背后用的是LLM做决策推理。

能帮你解决什么：

  • 不用学Pine Trade或Python量化库，用人话描述策略就能跑
  • 支持加密货币和股票市场
  • 完整的workflow自动化：数据获取→信号分析→下单执行→结果反馈
  • 适合想尝试量化但不想从零学编程的人

怎么用：

# 克隆仓库
git clone https://github.com/HKUDS/Vibe-Trading.git
cd Vibe-Trading

# 安装依赖
pip install -r requirements.txt

# 配置API密钥（交易所API + LLM API）
cp .env.example .env
# 编辑 .env 填入你的密钥

# 运行Agent
python main.py --strategy "当ETH突破2000美元时买入5%"

⚠️ 注意：这还是学术研究项目，不要拿真金白银去测试。先用模拟盘跑通再说。

2. Scrapling — 自适应Web爬虫框架

GitHub：D4Vinci/Scrapling

做过爬虫的人都知道，最头疼的不是写解析逻辑，而是反爬。Cloudflare、Akamai、各种JS挑战……Scrapling的思路是：与其硬刚反爬，不如让框架自己适应。

它的核心能力：

  • 自动绕过常见反爬：内置了多种反检测策略，不用手动配置headers和proxy
  • 自适应提取：即使页面结构变了，它能自动调整解析规则
  • 从单页到全站爬取无缝切换：同一个API，既能抓一个页面也能跑全站
  • 支持异步并发，速度够快

怎么装：

# pip安装
pip install scrapling

# 或者从源码安装
git clone https://github.com/D4Vinci/Scrapling.git
cd Scrapling
pip install -e .

用起来很简单：

from scrapling import Fetcher

# 自动处理反爬，直接拿数据
fetcher = Fetcher()
page = fetcher.get("https://example.com/products")

# 智能提取，不依赖固定CSS选择器
products = page.smart_extract("product listing")
for item in products:
    print(item["name"], item["price"])

3. CodeGraph — 给Claude Code加速的知识图谱

GitHub：colbymchenry/codegraph

用Claude Code做大型项目开发的人应该有过这种体验：每次问它一个跨文件的问题，它要先读一堆文件才能搞清楚上下文，token消耗大，响应也慢。

CodeGraph的解决方案是预构建代码知识图谱。它在你写代码之前，先把整个项目的函数调用关系、类继承结构、模块依赖全部索引好，存成本地图谱。Claude Code需要理解代码时，直接查图谱，不用逐文件扫描。

效果：

  • token消耗减少60-80%（不用每次都读原始文件）
  • 工具调用次数大幅降低
  • 100%本地运行，代码不离开你的机器
  • 支持Python、TypeScript、JavaScript

安装：

# 安装
npm install -g codegraph

# 在项目根目录生成知识图谱
cd your-project
codegraph index

# 现在用Claude Code时会自动加载图谱
# 减少token消耗，提升响应速度

4. OpenCut — 开源版剪映

GitHub：OpenCut-app/OpenCut

剪映很好用，但它是字节跳动的产品，数据都在他们服务器上。OpenCut做的事情和剪映类似——一个现代化的视频编辑器——但完全开源、可以本地部署。

技术栈是Electron + TypeScript，界面做得挺漂亮。支持常见的视频编辑功能：时间线编辑、多轨混音、字幕添加、特效转场。

适合谁：

  • 不想把素材传到云端的创作者
  • 需要二次开发定制功能的团队
  • 想在内网部署视频编辑工具的公司
  • 隐私敏感型用户

安装：

# 克隆
git clone https://github.com/OpenCut-app/OpenCut.git
cd OpenCut

# 安装依赖
npm install

# 启动开发模式
npm run dev

# 或者构建发布版
npm run build

5. SuperMemory — AI记忆引擎

GitHub：supermemoryai/supermemory

AI Agent最大的短板之一是记忆。每次对话都是从零开始，没有长期记忆能力。SuperMemory想解决这个问题——它是一个为AI时代设计的记忆API。

核心能力：

  • 极速存取：毫秒级向量搜索，百万条记忆也不卡
  • 可扩展架构：从小项目到大规模部署都能用
  • 标准API：任何AI应用都能接入，不管底层用的是什么模型
  • 支持时间衰减、关联检索、语义搜索

如果你在做AI Agent开发，这可能是目前最靠谱的记忆层方案之一。

快速开始：

# Docker部署
docker run -d -p 3000:3000 supermemory/supermemory

# 或者用npm
npx supermemory init
npx supermemory dev

# API调用示例
curl -X POST http://localhost:3000/api/memory \\
  -H "Content-Type: application/json" \\
  -d '{"content": "用户喜欢暗色主题，偏好TypeScript", "user_id": "user123"}'

# 检索相关记忆
curl "http://localhost:3000/api/memory/search?q=用户偏好&user_id=user123"
