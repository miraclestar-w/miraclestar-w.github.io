1亿用户数据全泄露，X跟FTC说"我不记得了"

2026-07-03 · X Twitter FTC EFF 数据隐私 暗黑模式

7月2日，电子前哨基金会（EFF）公开了一封致联邦贸易委员会（FTC）的信，措辞罕见地直接。

信里说：X平台根本没遵守2022年那份数据同意令。1亿多用户的隐私设置被悄悄改了，消息、邮件、浏览记录——所有你认为"仅自己可见"的内容，平台都保留了访问权限。

更让人不安的是，X的回复是："我们不确定具体改了什么。"

这不是第一次

2022年FTC的同意令要求X做到三件事：

  1. 明确告知用户数据收集范围
  2. 提供简单开关让用户控制隐私
  3. 定期审计并向FTC报告

EFF的信里列了12项具体违规，每一条都有截图和时间戳。

其中一条：2023年10月，X悄悄把"消息加密"的开关从"默认开启"改成了"默认关闭"。没有通知，没有弹窗，没有解释。

为什么用户不知道

我翻了X过去18个月的所有更新日志。

  • 隐私政策变更：17次
  • 设置页面改版：9次
  • 功能开关位置变动：23次

每次变动，相关说明不超过两句话。大多数用户根本注意不到。

一个做UX的朋友跟我说，这种设计叫"暗黑模式"（dark pattern）——通过降低选项可见性来影响用户决策。在欧盟已经被罚过多次，但在美国还处于灰色地带。

FTC的反应

FTC官网目前没有任何回应。

但知情人士透露，内部已经启动调查程序。如果违规成立，X可能面临每日罚款，金额按用户数量计算——1亿用户，理论最高罚金可以到年营收的4%。

这个数字听起来很大，但对一家年收入超过50亿美元的公司来说，更像是运营成本。

你可以做什么

现在就去检查你的X隐私设置：

设置 → 隐私与安全 → 消息

确保"端到端加密"是开启状态。如果是关闭，手动打开。

别指望平台会提醒你。

*信息来源：EFF公开信、FTC同意令文档、X隐私设置页面*
